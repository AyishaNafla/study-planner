# Study Planner

A simple web-based Study Planner developed using React. The application allows users to register and log in, manage their subjects, track study hours, and view their study progress through a dashboard.

## Features

* User Registration and Login
* User-specific subject management
* Add, edit, and delete subjects
* Track study hours
* Dashboard with study statistics
* Study progress indicator
* Protected routes for logged-in users
* Data persistence using JSON Server

## Technologies Used

* React
* React Router
* React Bootstrap
* Bootstrap
* Axios
* JSON Server
* JavaScript
* HTML5
* CSS3

## Getting Started

### Install Dependencies

```bash
npm install
```

### Start JSON Server

```bash
npm run server
```

### Start the React Application

Open another terminal and run:

```bash
npm run dev
```

The application will then be available through the local development URL shown in the terminal.

## Build

To create a production build:

```bash
npm run build
```
